// Featured Project 01

AWS 3-Tier Web Application

Highly-available, secure, multi-tier architecture deployed across isolated VPC subnets on AWS.

Tier 1 // Presentation Layer

Public Web Tier — React & Nginx

Public-facing EC2 instance running Nginx serves the compiled React frontend, handling client TLS/HTTPS and reverse-proxying dynamic API requests into the VPC interior.

Public Subnet EC2 Nginx React
Tier 2 // Logic Layer

Internal ALB & Auto-Scaling App Tier

Internal Application Load Balancer distributes API traffic across private Node.js / Express instances inside an Auto Scaling Group across multiple Availability Zones, scaling on CPU demand.

Private Subnet Internal ALB Auto Scaling Group Node.js / Express
Tier 3 // Data Layer

Isolated Database Tier — Amazon Aurora

Managed relational persistence in strictly isolated private DB subnets with chained security groups, automated multi-AZ replication, IAM authentication, and CloudWatch metric alarms.

Isolated Subnet Amazon Aurora / MySQL Security Groups CloudWatch
View Repository on GitHub
01

Network Segmentation & VPC Isolation

Architected custom VPC subnets so that only Web Proxies exist in public subnets, while application logic and Aurora database instances remain strictly isolated in private subnets with no direct internet access.

02

Security Group Chaining

Configured security groups referencing source security group IDs rather than open CIDR ranges: Aurora only allows port 3306 from App SG; App tier only allows port 4000 from the Internal ALB.

03

High Availability & Auto-Healing

Integrated CloudWatch CPU alarms triggering Auto Scaling policies across multiple Availability Zones, ensuring zero downtime if an individual instance fails or traffic spikes.
